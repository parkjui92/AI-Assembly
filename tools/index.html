국회사무처 2026년 신임관리자 교육 배포자료

입법조사관을 위한 MCP·API 도구 모음

Claude Code에 붙여 쓰는 법령·의안·입법례·재정·통계 자료원 (2026. 10. 26. 기준)

1. MCP와 API

  • API(Application Programming Interface): 기관이 자료를 기계가 읽는 형식(JSON·XML)으로 내어 주는 창구임
  • 예: 열린국회정보 API에 대수(AGE=22)를 넣으면 국회의원 발의 법률안 목록이 JSON으로 돌아옴
  • MCP(Model Context Protocol): API 같은 자료원을 Claude가 대화 중에 직접 부르는 도구로 연결하는 표준 규격임
  • 연결해 두면 "「국회법」 제79조의2 현행 조문 보여줘"라고 했을 때 Claude가 스스로 법령 API를 조회함
  • 고르는 순서
자료원의 형편 쓰는 방법
이미 만들어진 MCP가 있음 MCP를 설치해 대화로 조회함(2절)
MCP는 없고 Open API만 있음 API 명세서를 Claude Code에 주고 조회 스크립트 작성을 지시함
API 없이 웹 화면만 있음 화면에서 내려받은 hwp·pdf 파일을 kordoc으로 읽힘(3.7)
  • 직접 API를 익힐 필요는 없음. 다만 인증키 발급과 결과 대조는 사람이 맡음

2. Claude Code에 MCP를 붙이는 법

Claude Code 공식 문서(code.claude.com/docs/en/mcp)의 문법임.

# 내 컴퓨터에서 실행하는 서버(stdio): "--" 앞은 Claude 옵션, 뒤는 서버 실행 명령
claude mcp add [options] <이름> -- <실행 명령> [인자...]

# 원격 서버(HTTP)
claude mcp add --transport http <이름> <URL>

# 서버에 환경변수 넘기기: --env와 서버 이름 사이에 다른 옵션을 하나 둠
claude mcp add --env KEY=값 --transport stdio <이름> -- <실행 명령>

# 관리
claude mcp list          # 연결 목록과 상태
claude mcp get <이름>    # 상세
claude mcp remove <이름> # 삭제
# 대화 중에는 /mcp: 서버 상태 확인, 원격 서버 로그인
  • 적용 범위(--scope)
  • local(기본값): 지금 프로젝트에서 나만 씀. 설정은 ~/.claude.json에 저장됨
  • user: 내 모든 프로젝트에서 씀. 설정은 ~/.claude.json에 저장됨
  • project: 프로젝트 폴더의 .mcp.json에 저장돼 폴더를 받은 사람과 공유됨
  • 인증키 보관
  • 키는 셸 환경변수로 둠. 예: ~/.zshrc에 export LAW_OC=본인 발급 값
  • .mcp.json에는 ${LAW_OC}처럼 변수 이름만 적음. ${변수}와 ${변수:-기본값} 확장은 공식 지원됨
  • --env에 키 값을 직접 적으면 그 값이 서버 설정과 함께 저장되므로, 공유하는 폴더에서는 쓰지 않음
  • 프로젝트에 .env 파일을 둘 때는 .gitignore에 등록해 저장소에 올라가지 않게 함
  • 승인 절차: 남이 준 폴더의 .mcp.json 서버는 대화형 실행에서 사용 전에 승인을 물음. 모르는 서버는 승인하지 않음

3.1 법령·조문 현행 확인, 판례·헌재결정

국가법령정보 공동활용 Open API (법제처, open.law.go.kr)

항목 내용
주는 것 현행법령(시행일·공포일 기준)·법령 연혁·영문법령·조항호목 단위 본문, 신구법 비교, 3단 비교, 위임법령, 행정규칙, 자치법규, 판례, 헌재결정례, 법령해석례, 행정심판례, 각 위원회 결정문, 중앙부처 1차 해석, 조약, 별표·서식, 법령용어
발급 open.law.go.kr 회원가입 → OPEN API 신청(활용할 데이터 선택) → 담당자 승인 후 사용. 승인은 신청 후 1~2일 이내 처리로 안내됨
인증 모든 요청에 OC 값(본인 발급 값)을 붙임
요청 형식 목록: https://www.law.go.kr/DRF/lawSearch.do?OC=본인 발급 값&target=대상&type=JSON&query=검색어
본문: https://www.law.go.kr/DRF/lawService.do?OC=본인 발급 값&target=대상&MST=법령일련번호&type=JSON
주요 target law 현행법령 · eflaw 시행일 기준 법령 · prec 판례 · detc 헌재결정례 · expc 법령해석례 · oldAndNew 신구법 · thdCmp 3단 비교
주의 이용조건 위반·과도한 트래픽 등으로 이용이 제한될 수 있음. 대량 자동 호출은 상한을 정해 시킴

korean-law-mcp (github.com/chrisryugj/korean-law-mcp, MIT)

  • 위 법제처 API를 감싼 MCP임. 법령·판례·헌재결정·해석례·자치법규·조약 검색과 함께 다음 기능을 제공함
  • 인용 검증(verify_citations): 답변에 나온 조문·판례가 실제로 있는지 법제처 자료와 대조함
  • 시점 적용 법령(applicable_law): 특정 일자에 시행 중이던 조문과 부칙 경과규정을 찾음
  • 개정 추적(amendment_track): 신구대조, 조문별 개정 이력
  • 위임입법 점검: 하위법령에 위임한 조항 중 시행령이 아직 없는 조항을 찾음
  • 설치 방법 셋 중 하나를 고름
방식 명령 특징
Claude Code 플러그인 /plugin marketplace add chrisryugj/korean-law-mcp
/plugin install korean-law@korean-law-marketplace		 설치가 가장 간단함. 제작자가 운영하는 공개 서버(mcp.gomdori.app)에 연결되며 키는 선택 입력
내 컴퓨터에 설치(자동) npx --ignore-scripts --omit=optional korean-law-mcp setup 키 입력과 클라이언트 등록을 마법사가 처리함. Claude Code 설정에는 ${LAW_OC} 참조를 넣음
내 컴퓨터에 설치(수동) npm install --ignore-scripts --omit=optional -g korean-law-mcp 후 설정에 LAW_OC 환경변수 지정 Node.js 20.19 이상 필요
  • 시킬 일 예시
  • "「국회법」 제79조의2 현행 조문과 시행일을 원문 그대로 보여줘"
  • "이 검토보고서 초안에 나온 조문·판례 인용을 전부 검증해 실존 여부를 표로 정리해줘"
  • "개정안 제12조와 같은 내용을 다룬 헌재결정례를 찾아 사건번호·종국일자·결정 요지를 정리해줘"
  • 주의
  • 플러그인 방식은 조회 내용이 외부 공개 서버를 거침. 검토 중인 내용을 넣어 조회할 때는 내 컴퓨터 설치 방식을 씀
  • 도구가 돌려준 조문도 최종 문안에 넣기 전에 국가법령정보센터 화면에서 시행일을 다시 확인함

legalize-kr (github.com/legalize-kr/legalize-kr)

  • 대한민국 법령을 법령 하나당 Markdown 파일, 개정 하나당 실제 공포일자의 Git 커밋으로 관리하는 저장소임
  • git clone https://github.com/legalize-kr/legalize-kr 후 키·인터넷 없이 내 컴퓨터에서 조문·개정 연혁을 검색함

  • 주의: 민간이 관리하는 사본이므로 최종 확인은 국가법령정보센터 원문으로 함

항목 내용

의안정보시스템 (likms.assembly.go.kr)

  • 의안별 심사정보 화면에 의안번호·제안일자·제안자·제안회기, 제안이유 및 주요내용, 심사진행단계(접수 → 위원회 심사 → 체계자구 심사 → 본회의 심의 → 정부이송 → 공포)가 나옴
  • 비고란에 비용추계 관련 제출 상태(예: '비용추계요구서 제출됨')가 표시됨
  • 열린국회정보 API 결과의 상세 주소(DETAIL_LINK)가 이 화면으로 연결됨

국회회의록 시스템 (record.assembly.go.kr)

  • 제헌국회부터 제22대까지 본회의·상임위원회·예산결산특별위원회·특별위원회·국정감사·국정조사·전원위원회 회의록을 제공함
  • 국정감사 회의록은 열린국회정보 데이터가 회의별 PDF 내려받기 주소를 함께 제공함
  • 시킬 일 예시: "이 회의록 PDF에서 개정안 제5조에 관한 발언만 찾아 발언자·직위·요지·쪽 번호 표로 정리해줘"
  • 대조할 것: 발언자 이름·직위, 회의 일자·차수, 직접 인용 문장이 글자 그대로인지

국회입법조사처 발간물 API (공공데이터포털 data.go.kr/data/3037296)

  • 연구보고서·학술지·세미나 및 간담회 자료·조사처 알림지·정책연구용역자료의 목록과 상세를 제공함
  • 공공데이터포털 활용신청, 개발·운영 단계 모두 자동승인, 개발계정 트래픽 10,000으로 표시됨, JSON·XML

open-assembly-mcp (github.com/kyusik-yang/open-assembly-mcp, Apache-2.0)

  • 열린국회정보 API를 감싼 개인 개발 MCP임. 의안·의원·표결·위원회 구성·국회입법조사처 보고서 등을 조회함
  • 설치 안내: uvx open-assembly-mcp --setup(uv 설치 필요). 인증키는 환경변수 ASSEMBLY_API_KEY
  • 프로젝트 .mcp.json에 직접 적을 때는 키 자리에 변수 이름만 둠
{
  "mcpServers": {
    "open-assembly": {
      "command": "uvx",
      "args": ["open-assembly-mcp"],
      "env": { "ASSEMBLY_API_KEY": "${ASSEMBLY_API_KEY}" }
    }
  }
}
  • 주의: 이용자가 적은 개인 저장소임. 업무에 쓰기 전 코드와 갱신 상태를 확인하고, 확인 전에는 API 스크립트 방식을 씀

3.5 비용추계·재정

  • 근거: 「국회법」 제79조의2. 의원이 예산상 또는 기금상의 조치를 수반하는 의안을 발의할 때 국회예산정책처의 추계서 또는 추계요구서를 함께 제출하고, 정부 제출 의안은 추계서와 재원조달방안 자료를 첨부함
  • 비용추계 요구: 위원회 또는 의원이 국회예산정책처에 요구함(FAX 또는 국회종합입법지원 시스템). 처리 부서는 추계세제분석실임
  • 회답은 비공개 원칙임. 요구 위원회 또는 의원이 공개에 동의한 경우에만 공개됨. 공개 여부를 확인하기 전에는 AI에 넣지 않음

국회예산정책처 재정경제통계시스템 Open API (nabostats.go.kr 'Open API')

  • 서비스 통계 목록, 통계 세부항목 조회, 통계 데이터 조회, 통계 용어사전 조회를 제공함
  • 사이트에서 인증키를 발급받아 씀. '통계코드 검색' 메뉴로 통계 코드를 찾음

열린재정 Open API (openfiscaldata.go.kr '재정정보 공개 > OPEN API')

  • 재정수입 구조, 국세수입 추이, 재정사업별 예산 시계열, 재정사업 집행실적, 민간투자사업 현황, 경제·국제비교 통계 등 약 150개 데이터를 제공함
  • 발급: 본인인증 → 신청자명·활용용도·활용 목적 입력 → 개인정보 수집·이용 확인 후 발급. 인증키는 최대 10개까지 발급 가능함
  • 데이터별 상세 화면의 'Open API' 탭에서 요청 주소와 인자를 확인하고 시험 호출함
  • 시킬 일 예시
  • "열린재정 API로 이 법률안과 관련된 재정사업의 최근 5년 예산과 집행실적을 표로 가져와줘"
  • "비용추계서의 연도별 표를 다시 계산해 합계가 맞는지 검산하고, 대상 인원·단가 가정이 조문 내용과 맞는지 표시해줘"
  • 대조할 것: 금액·단위·회계연도, 합계 검산, 추계 전제와 조문의 대응

5. 보안·이용 수칙

  • 소속 기관의 생성형 AI 이용 지침이 이 자료보다 우선함
  • 넣지 않는 것: 비공개 문서, 공개 동의 전의 비용추계 회답, 공개되지 않은 부처 제출자료, 검토 중인 내부 의견, 개인정보가 담긴 자료. 공개된 의안·법령·회의록·통계로 시작함
  • 외부 서버를 거치는 도구를 구분함: korean-law-mcp 플러그인·웹 커넥터는 제작자 공개 서버를 거쳐 조회함. 검토 중인 문안을 넣는 조회는 내 컴퓨터 설치 방식으로 함
  • 인증키를 채팅 창에 붙이지 않음: 대화 기록에 남음. Claude에게는 "키는 환경변수 LAW_OC에서 읽어"처럼 변수 이름만 알려 줌
  • 키를 주소(URL)에 넣는 방식을 줄임: 주소에 붙은 키는 접속 기록에 평문으로 남을 수 있음. 헤더나 환경변수로 넘기는 방식을 지원하는 도구는 그쪽을 씀
  • 유출 의심 시 재발급함: 법제처는 마이페이지 'API인증키관리', 열린국회정보는 '인증키 발급내역'에서 관리함
  • MCP 설치는 남이 만든 코드를 내 컴퓨터에서 실행하는 일임: Claude Code 공식 문서는 연결 전에 각 서버를 신뢰할 수 있는지 확인하라고 경고하며, 외부 내용을 가져오는 서버는 프롬프트 인젝션 위험에 노출될 수 있다고 안내함. 공식 저장소의 설치 명령만 복사해 씀
  • 프롬프트 인젝션 대비: 외부 웹페이지·문서 속에 숨긴 지시문이 AI를 조종하려 할 수 있음. 외부 자료를 읽힌 뒤 Claude가 제안하는 명령·파일 수정은 승인 전에 읽어 봄
  • 호출 한도를 지시에 넣음: 공공 API는 계정별 호출 한도가 있음. "100건씩 끊어서, 한 번에 1,000건까지만"처럼 상한을 정해 시킴

6. 이용 시 유의

  • 절차·메뉴 이름·요청 주소는 2026. 10. 26. 기준임. 포털 개편으로 바뀔 수 있으므로 쓰기 전에 각 사이트의 명세서와 공지사항을 확인함
  • 각 API의 호출 한도·승인 방식은 사이트 화면에 표시된 값을 따름
  • 도구가 돌려준 결과는 초안 재료임. 조문·수치·인용은 원문 화면과 대조한 뒤 검토보고서에 씀
