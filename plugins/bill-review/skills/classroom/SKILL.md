# 교육용 첫 실행

목표는 짧은 검토보고서 초안과 검증 기록을 직접 읽는 것이다. 설치 안내만 하고 끝내지 않는다.

1. 이 스킬 기준 폴더의 두 단계 위가 플러그인 루트다. `scripts/preflight.py`를 Python으로 실행한다. Windows에서는 `py -3`, `python`, `python3` 중 실제 동작하는 명령을 쓴다. 새 도구를 임의로 설치하지 않는다
2. 법령 도구(korean-law)가 도구 목록에 보이는지 확인한다. 없으면 `bill-sources` §1의 연결 안내를 보이고, 연결 전까지는 원장을 만들 수 없어 검문소가 보류된다는 것을 알린다
3. `../bill-review/references/classroom.md`를 읽는다. 사용자가 준 의안원문과 의안번호를 쓴다. 실제 검토보고서 파일이 같은 폴더에 있으면 정답지로 따로 두고 열지 않는다
4. `../bill-review/SKILL.md`를 읽고 같은 팀·파일·관문을 쓴다. 모든 팀원에게 **교육용 모드**, 입력과 출력의 절대 경로, 교육용 범위 문서와 필요한 스킬 파일의 절대 경로를 전달한다. 메인 세션이 조율한다
5. 쟁점은 최대 2개. 사용자에게 실제 쟁점을 보여 준 뒤 승인을 기다린다. **테스트를 진행하는 에이전트가 사용자의 승인 발언을 만들어 넣지 않는다**
6. 끝나면 파일 경로, 조문 대조 결과, 검수 판정, `[확인 필요]`·`〔판단 필요〕` 목록, 사람이 원문과 맞춰 볼 조문 위치를 보여 준다. 대비표 한 행을 국가법령정보 원문과 직접 대조해 보도록 안내한다. 한글 변환과 실제 검토보고서 대조표("실제 검토보고서와 비교해줘")는 후속 요청으로 한다

Sonnet과 medium을 수업 기본값으로 **안내**하되 사용자의 모델·설정을 임의로 바꾸지 않는다. 설치·로그인 성공과 모델의 실제 응답 성공을 구분한다. 인증 오류·사용량 제한이 나면 그 사실을 알리고 진행 중인 단계에서 멈춘다.
