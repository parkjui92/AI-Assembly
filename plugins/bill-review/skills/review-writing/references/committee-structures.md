# 위원회별 골격 — 관측한 변형

> 제21대 국회 상임위원회 검토보고서 4건을 본 것이다(목차와 절 제목만 기록, 본문은 싣지 않음).
> 표본이 작다. 실제로 쓸 위원회의 직전 검토보고서를 입력으로 주면 그 골격을 따른다.

| 관측 | 법률안 유형 | 골격 |
|---|---|---|
| 정무위원회(2024) | 일부개정 | Ⅰ. 제안경위(1. 제안자 2. 제안일 3. 회부일) → Ⅱ. 제안이유 및 주요내용 → Ⅲ. 검토의견: (주제) — 쟁점 하나면 장 제목에 붙임, □ → ○ → - |
| 보건복지위원회(2023) | 일부개정 | Ⅰ. 개요 → 1. ○○의원 대표발의안 → 가. 제안경위((1) 제안자 (2) 제안일 (3) 회부일) · 나. 제안이유 및 주요내용 → Ⅱ. 주요 내용별 검토 → 1. (쟁점)(○○의원안) → 가. 개정안의 내용 · 나. 검토의견 · 다. 관계 부처 및 관련 단체 의견, □ → - |
| 보건복지위원회(2021) | 전부개정 | Ⅰ. 제안이유 및 주요내용 → Ⅱ. 개정안의 취지 및 주요내용(취지 · 주요내용 · 현행 대비 비교 · 부처·단체 의견 · 전부개정 필요성) → Ⅲ. 주요 사항별 검토(장별: 총칙 · … · 벌칙 · 부칙) |
| 기획재정위원회(2022) | 제정 | Ⅰ. 제안경위(가. 발의자 나. 발의일 다. 회부일) → Ⅱ. 제안이유 → Ⅲ. 주요내용 → Ⅳ. 검토의견 → 1. 법 제정 필요성 검토 → 2. 조문별 검토(가. 총칙(안 제1장: 제○조부터 제○조까지) …), ○ → - |

## 공통
- 표지: 회기·차수 위원회 / 법률안명 / `검 토 보 고` / `▣ ○○○의원 대표발의(의안번호 제○○○○○호)` / 연월 / 위원회·(수석)전문위원
- 여러 법률안을 함께 검토하면 표지에 법률안마다 `▣` 줄, Ⅰ장에 법률안마다 제안경위, 쟁점 제목 끝에 `(○○○의원안)`
- 끝에 `문 의 처`(전화번호)와 `【참고】`(통계표 등)를 두기도 한다 — 초안에서는 `〔 〕` 자리로
