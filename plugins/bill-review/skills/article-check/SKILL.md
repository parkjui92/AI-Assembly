# 조문 대조 검문소 — "조문 조심해줘"는 파일로, 대조는 코드로

법률안 검토보고서의 가장 큰 위험은 **그럴듯한 조문**이다. 없는 조문 번호, 개정 전 문구, 바뀐 부처 이름.
문장으로 조심하라고 부탁해도 같은 모델이 같은 착각을 한다. 그래서 대조는 **조회해 둔 원문과 초안의 글자를 코드로** 맞춘다.

## 1. 흐름
```
설계자: 의안원문 → article_check.py --list → 조문 원장 목록(01 §8)
조사관(원장 분할): 법령 도구로 기준일 원문 조회 → 03b_조문원장/<법령>@<기준일>.md  (응답 그대로)
집필가: 원장 글자로 대비표·각주 작성 → 스스로 검문
팀장: article_check.py → 04c_조문대조.md   ✕ 있으면 산출 보류
검수관: 원장 조문 2~3개를 다시 조회해 원장과 견줌 (원장이 조회 결과와 같은지)
```

## 2. 원장 파일 형식 — `_workspace/03b_조문원장/<법령명>@<기준일>.md`
```
- 법령: 자전거 이용 활성화에 관한 법률
- 기준일: 2023-02-16
- 범위: 제2조, 제3조, 제22조, 제23조        (법령 전문을 받았으면 '전문')
- 대상법률: 예                              (검토 대상 법률 하나에만)
- 없음: 제24조                              (조회했으나 그 시점에 없던 조문 — 없으면 줄을 지운다)
- 조회: korean-law get_law_text(mst=…, jo=제22조, efYd=20230216) · 2026-10-20 16:10
- 조회: (조문마다 한 줄씩 더해도 된다)
---
(도구 응답 원문 — 한 글자도 바꾸지 않는다. 조문마다 이어 붙인다)
```
- 머리말의 `- 법령:` `- 기준일: YYYY-MM-DD` `- 조회:` 세 줄과 `---` 줄은 필수다. 빠지면 검문소가 종료코드 2로 멈춘다
- 본문에서 `제N조(` 로 시작하는 줄을 조문 머리로 읽는다. `<개정 2017.7.26>` 같은 연혁 표시는 대조할 때 무시한다
- 같은 법령을 기준일과 오늘 두 판으로 받으면 파일도 둘이다. 검문은 `--date`로 고른 기준일 판으로 한다
- 원장은 조사관만 쓴다. 집필가·팀장은 고치지 않는다(틀렸으면 다시 조회해 새로 쓴다)

## 3. 실행
```bash
S=<이 스킬 폴더>/scripts
python3 $S/article_check.py --selftest                                   # 설치 확인
python3 $S/article_check.py --list --law "자전거 이용 활성화에 관한 법률" _workspace/00_input/의안원문.md
python3 $S/article_check.py _workspace/04_검토보고서.md \
   --ledger _workspace/03b_조문원장 --bill _workspace/00_input/의안원문.md --date 2023-02-16 \
   > _workspace/04c_조문대조.md ; echo "종료코드 $?"
```
윈도에서 `python3`가 없으면 `py -3` 또는 `python`. 표준 라이브러리만 쓴다(설치할 것 없음).

| 종료코드 | 뜻 | 팀장이 할 일 |
|---|---|---|
| 0 | 통과(✕ 없음, △는 있을 수 있음) | 관문②로 |
| 1 | **불통과 — 산출 보류** | 원장 미조회면 조사관에게 조회, 초안 글자가 틀렸으면 집필가에게 수정 → 다시(최대 2회) |
| 2 | 실행 오류(파일 없음·원장 형식) | 고치고 다시. 검문 미실행으로 넘어가지 않는다 |

## 4. 무엇을 보나
| 대상 | ✕(보류) | △(사람 확인) |
|---|---|---|
| 「법령」 제N조 · 같은 법 · 현행법 제N조 · 약칭 | 원장에 그 법령·기준일 판 없음 / 조회했는데 없음(`없음:`) / 전문 원장에 그 조문 없음 / 인용한 항·호가 그 조문에 없음 | 항·호 확인 불가 · 법령명만 인용했는데 원장 없음 · 문장에 `[확인 필요]`가 붙은 인용 |
| 안 제N조 | 의안원문에 그 조문이 없음 | 의안원문을 주지 않음 |
| 대비표 현 행 칸 | 원장 원문과 글자가 다름(공백·가운뎃점·따옴표·연혁 표시는 무시) / 조문 미조회 | 대상 법률 원장 없음 |
| 대비표 개 정 안 칸 | `-` 줄 사이의 글자가 의안원문에 없음 | — |
| 대비표 표기 | 현행 칸 `(현행과 같음)` · 개정안 칸 `(생 략)` · 개정안 칸 `<신 설>` · 현행 칸 `<삭 제>` · 생략 범위가 양쪽에서 다름 · 개정안 `(현행과 같음)`인데 현행이 `(생 략)`이 아님 · 수정의견 칸 `(생 략)` | — |

표 찾기: 머리 칸이 `현 행`·`개 정 안`(공백 무관)인 마크다운 표. 표기 약속은 `review-writing` §12.

## 5. 이 검문소가 보지 못하는 것
- **해석** — 글자가 같아도 뜻을 잘못 옮길 수 있다(검수관·사람)
- **원장 자체** — 원장은 조회 결과를 옮긴 파일이다. 검수관이 몇 조문을 다시 조회해 견주는 이유다
- **기준일이 맞는지** — 01 §2에서 정하고 관문①이 본다
- 판례·외국 입법례·통계의 실재 — 조사 장부의 출처와 fact-verify
- 표 밖 문장 속 조문 내용 서술("제22조는 등록을 의무로 정함" 같은 요약) — 조문 번호는 보지만 요약이 맞는지는 못 본다
