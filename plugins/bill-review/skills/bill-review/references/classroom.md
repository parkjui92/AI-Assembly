# 교육용 실행 범위

사용자가 교육용 첫 실행을 요청했거나 `/bill-review:classroom`을 실행한 경우에만 적용한다. 이 문서의 범위를 팀원 전원에게 전달하고 `00_요청.md` ④에 기록한다. 표준 모드의 전체 검토를 마쳤다고 보고하지 않는다.

| 항목 | 교육용 범위 |
|---|---|
| 입력 | 사용자가 준 의안원문 1건(공개 의안). 실제 검토보고서가 있으면 **정답지로 따로 두고 열지 않는다** |
| 기준 시점 | 지난 법률안이면 위원회 상정일(열린국회정보 `ALLBILL`), 계류 중이면 오늘 |
| 조사 | 법령 조회(korean-law)와 열린국회정보 의안 API만. 웹 검색은 쟁점 하나당 5회 이내. 부족한 것은 '부처·이해관계자에게 받을 것'으로 |
| 쟁점 | 최대 2개 |
| 착안점 | 1·2번 파일과 신호로 고른 파일의 해당 절만. 전수 대조를 하지 않았으면 "부분 대조"라고 01 §5에 적는다. 안 본 행을 비해당으로 쓰지 않는다 |
| 팀 | 설계자·검수관·조사관 2명(쟁점 1 · 원장 1)·집필가. 변환가는 사용자가 한글 변환을 요청할 때만 |
| 원고 | Ⅰ·Ⅱ장 + Ⅲ장 쟁점 1~2개, 대비표 1~2개. 자료에 없는 사실·의견·조문을 만들지 않는다 |
| 종료 | 04 원고 + 04c 조문 대조 결과 + 05 최종 검수 판정 + 사람이 판정할 목록. 한글 변환과 실물 대조표는 후속 요청 |

- 관문① GO → **사용자의 실제 승인** → 조사·원장·집필 → 검문 통과 → 관문② 통과를 모두 거친다. [필수]가 남으면 보류한다. 사용자 대기시간은 실행시간과 따로 적는다
- 진행 중인 `_workspace/`를 옮기거나 덮어쓰지 않는다. 다른 법률안은 다른 작업 폴더에서
- 역할별 모델은 정의를 따른다. 세션 모델이 Sonnet이면 설계자·집필가·검수관도 Sonnet이다
- 수업 시간에 맞추려고 관문·검문을 건너뛰지 않는다. 시간이 모자라면 쟁점을 하나로 줄인다
