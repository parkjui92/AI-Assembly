# 두 관문의 판정 기준 · 실물 대조표

실패는 두 곳에서 온다. **방향 실패** — 쟁점이 빗나간 채 조사·집필이 끝난다. **근거 실패** — 그럴듯한 문장 속에
원장에 없는 조문, 장부에 없는 입법례, 부처 의견을 사실처럼 쓴 문장, 한쪽 논거만 든 결론이 섞인다. 성격이 달라서 관문이 둘이다.

| | 관문① 설계 판정 | 관문② 초안 검수 |
|---|---|---|
| 시점 | 설계 직후, 조사 전 | 집필·조문 대조 검문 후, 변환 전 |
| 대상 | `01_검토설계.md` | `04_검토보고서.md` |
| 대조 기준 | `00_요청.md` · 의안원문 · `review-criteria` 해당 파일 · `내_검토기준.md` | `03_근거장부.md` · `03b_조문원장/` · `04c_조문대조.md` · `01` · `00_요청.md` · 의안원문 |
| 판정 | GO / NO-GO | 통과 / 수정 필요 |
| 저장 | 팀장이 `02_설계판정.md` | 팀장이 `05_검수판정.md` |

## [필수]와 [권고]
- **[필수]** — 그대로 두면 **틀린 보고서가 나가는 것.** 원장에 없는 조문·틀린 조문 글자, 장부에 없는 근거, 부처·단체 주장을 사실로 단정, 빠진 쟁점, 요청과 다른 법률안·기준 시점, 지어낸 의견·출처·판례, 검문 ✕ 잔존, 찬반이 갈리는 판단을 한쪽 논거로만 결론
- **[권고]** — 고치면 **나아지는 것.** 어조 한 단계 조정, 표현, 단락 순서, 더 강한 근거로 바꿀 여지
- 판정 규칙: 관문①은 **[필수] 1건 이상이면 NO-GO**. 관문②는 [필수] 1건 이상이면 "수정 필요"
- 애매하면 "이게 위원 질의나 부처 반론에서 무너지는가"를 묻는다. 무너지면 [필수]

## 관문① 점검표 — 설계 판정

**먼저 `00_요청.md`와 의안원문만 읽고** 법률안·관점·기준 시점과 내가 본 쟁점 후보 2~3개를 따로 적는다. 그 뒤에 `01`을 연다.

| # | 볼 것 | [필수]가 되는 경우 |
|---|---|---|
| 1 | **요청 반영** — 법률안·위원회·관점·산출 범위 | 요청한 관점이 쟁점에서 빠지거나 뒤로 밀림 / 다른 법률안으로 설계 |
| 2 | **의안 정보** — 의안번호·제안자·제안일·회부일·위원회 | 모르는 값을 `[조사 필요]` 없이 채움 |
| 3 | **기준 시점** — 무엇을 '현행'으로 볼지, 제안일~기준일 사이 개정 여부 | 기준일 없음 / 지난 법률안인데 오늘 현행으로 대조하도록 설계 |
| 4 | **유형·구조** — 일부개정·제정 등, 개정 대상 조문과 방식 | 개정 대상 조문 누락 |
| 5 | **제안이유 대 조문** — 말하는 것과 바꾸는 것을 나란히 | 어긋남이 보이는데 쟁점 후보로 다루지 않음 |
| 6 | **착안점 대조표** — 신호로 고른 파일의 착안점 행이 빠짐없이 있는가 | 행 수가 파일과 다름(일괄 비해당은 행 수로 센다) / 이유 없는 비해당 / 신호가 있는데 파일을 안 폄 |
| 7 | **쟁점** — 여섯 칸(쟁점 문장·근거 착안점·관련 조문·필요한 근거와 자료원·예상 입장·갈 수 있는 결론) | 근거를 구할 길이 공개 자료로도 의견 조회로도 없음 / 쟁점 문장에 확인 안 된 사실 / 결론을 미리 한쪽으로 정함 |
| 8 | **목차** — `review-writing` 골격, 쟁점과 1:1 | 쟁점과 목차가 어긋남 |
| 9 | **조문 원장 목록** — 개정 대상 조문(현행)·인용될 다른 법률·하위법령, 기준일 | 개정 대상 조문이 목록에 없음 |
| 10 | **조사 분할** — 원장 분할이 있는가, 근거 번호 겹침 없음 | 원장 분할 없음 / 번호 충돌 |
| 11 | **확인할 전제** — 질문마다 기본 가정 | 쟁점을 가르는 전제를 묻지 않고 단정 |

**재판정(개정 뒤)** — 직전 [필수]마다 반영됐는지부터 본다. 반복된 [필수]도 해결 전에는 통과시키지 않는다.
**권고가 요청을 깎을 때** — 쟁점을 빼라고 권하면 그러면 보고서에서 무엇이 빠지는지 함께 적는다. 뺄지는 사용자가 정한다.

## 관문② 점검표 — 초안 검수 (여섯 축)

### 축 1 — 쟁점
- 승인된 쟁점(01 §6과 `00_요청.md` ⑤의 사용자 수정)이 **모두** 검토의견이 됐는가, 순서가 승인대로인가
- 승인받지 않은 쟁점이 끼어들었는가 · 요청의 관점이 분량에서도 앞에 서 있는가

### 축 2 — 근거 대조
- 본문의 사실·통계·입법례·판례·부처 의견을 **장부와 하나씩** 맞춘다. 장부에 없으면 [필수]
- 통계에 기준연도와 출처가 있는가 · 외국 입법례에 원문 법령명과 번역 출처가 있는가
- Ⅱ장(제안이유 및 주요내용)이 의안원문 글자 그대로인가

### 축 3 — 조문
- `04c_조문대조.md`를 직접 읽는다(집필가의 "통과" 보고를 믿지 않는다). ✕가 남았으면 [필수], △는 본문이 어떻게 다뤘는지 본다
- **원장 표본 재조회** — 결론을 받치는 조문 2~3개를 기준일로 다시 조회해 원장과 견준다. 다르면 [필수]
- **해석** — 조문을 맞게 요약했는가(재량 `할 수 있다`를 의무로, 등록 `임의`를 `의무`로 바꿔 쓰지 않았는가). 다른 법률 조문과 비교할 때 같은 층위(법률 대 법률)인가
- 기준일과 오늘 현행이 다르면 본문이 기준일을 밝혔는가

### 축 4 — [확인 필요] · 〔판단 필요〕
- 장부의 `[확인 필요]`·미확보 항목이 본문에서 단정으로 바뀌었는가 = [필수]
- 지어낸 부처 의견·출처·판례가 있는가 = [필수]
- 표시가 지나쳐 문서가 읽히지 않는 정도인가 — 그러면 [권고]로 의견 조회 목록에 넘길 것을 제안

### 축 5 — 중립성·결론
- 찬반이 갈리는 정책 판단을 한쪽 논거로만 결론 냈는가 = [필수]
- 결론 유형(긍정 / 중립·신중)이 근거의 무게와 맞는가 · 긍정 결론이면 빠뜨린 쟁점이 없는지 한 번 더
- 위헌·위법 단정이 판례·조문 원문 근거 없이 나왔는가 = [필수]
- 수정의견 대비표가 있으면 그 근거가 본문에 있는가

### 축 6 — 문체·형식 (`review-writing` §13 점검 목록)
- 골격·번호 · □·○·- 통일 · 개조식 종결 · `판단됨`·`사료됨` 없음 · 법령명 `「 」`와 약칭 · 조문 표기 붙여 쓰기 · 표 제목·단위·자료 · 마크다운 표기 약속

### 그리고 — 점검표 밖을 한 번 훑는다
집필가는 받은 목록만 자기 점검한다. 결함은 목록 밖에서 나온다. **같은 대상의 이름이 한 문서 안에서 흔들리는지, 각주와 본문의 조문 번호가 같은지, 대비표 밖 문장의 조문 요약이 대비표와 맞는지**를 따로 본다.

## 실물 대조표 — AI 초안과 실제 검토보고서 (교육 실습 · 사후 점검)

정답지(실제 검토보고서)는 **초안과 관문②가 끝난 뒤에** 처음 연다. 먼저 열면 초안이 정답지를 닮아 대조가 무의미해진다.

1. 실제 검토보고서에서 **쟁점 단위**를 뽑는다 — 검토의견의 소제목·`첫째/둘째`·수정의견 하나하나가 단위다. 실물의 결론 유형(긍정 / 중립·신중 / 수정의견)도 적는다
2. AI 초안의 쟁점 단위를 같은 방식으로 뽑는다
3. 짝을 짓고 판정한다

| 판정 | 뜻 |
|---|---|
| **맞음** | 실물과 같은 쟁점을 같은 방향(결론 유형·핵심 논거)으로 짚음 |
| **부분** | 같은 쟁점을 짚었으나 방향·핵심 논거·수정의견이 다름 |
| **놓침** | 실물에 있는데 초안에 없음 — **원인**을 적는다: 공개 자료 밖(부처 의견·집행 자료) / 착안점이 있었는데 안 봄 / 조사 상한 / 기준 시점 |
| **틀림** | 초안의 사실·조문·해석이 틀림(실물과 다른 것이 아니라 원문과 다른 것) |
| **과잉** | 실물에 없는 쟁점을 초안이 올림 — 쓸모 있는 추가인지(교재 착안점에 근거) 군더더기인지 따로 표시 |

```
| # | 실물 쟁점(쪽) | 초안 쟁점(위치) | 판정 | 근거·원인 |
|---|---|---|---|---|
| 1 | 점검 주기 단축의 실효성(p.4) | Ⅲ-1 나. 첫째 | 부분 | 초안은 인력 부족까지 짚었으나 실물의 대안(위험 등급별 주기)은 없음 |
```
- 끝에 집계(맞음·부분·놓침·틀림·과잉 건수)와 **놓침 원인별 건수**를 단다 — "AI가 놓친 쟁점은 어디서 오는가"의 답이다
- 실물이 틀렸거나 시점이 지나 달라진 것은 `시점 차이`로 따로 적는다. 실물을 정답으로만 보지 않는다
